# PRO SIDE BADGE SPEC

## Overview

ADDING THE PRO BADGE TO THE SIDEBAR FOR FILES AND IMAGES ITEM TYPE

### Requirements

Use ShadCN UI to create a Pro Badge component that can be used in the sidebar for files and images item type. The badge should be visually distinct and indicate that the user has access to pro features.
The Badge should be placed next to the item name in the sidebar and should be responsive to different screen sizes. The badge should also have a tooltip that displays "Pro Feature" when hovered over.
The Badge should be clean and simple.
